## 📖 Overview
The **Institute of Digital Risk (IDR)** is a modern, single-page responsive website designed for an industry-led training and deployment institute. It bridges the gap between academic theory and real-world execution, focusing on cultivating elite digital, cyber, and tech risk practitioners for high-consequence environments. 

**This platform serves as a modern and scalable entry point for organizations and practitioners to connect, learn, and secure their digital posture.**

The project includes a custom brand identity (logo variants) and a fully developed, high-contrast digital homepage experience.


## ✨ Core Features
We implemented the core requirements through a sleek, premium UI structured with comprehensive responsiveness across mobile, desktop, and any device:

### 1. Immersive Hero Display
Features an engaging, 3D CSS-animated cyber network model (`X/Y/Z` rotation) with a sticky glassmorphism navigation bar, bold typography, and direct calls-to-action to engage users immediately.

### 2. Detailed About IDR Section
Dual-stacked information boxes displaying the balance between rigorous **🎓 Academic** theory (UK university partnerships) and **⚙️ Practical** industry deployment. It highlights the unique value proposition of the institute.

### 3. Interactive Service Pillars Model
Three interactive, purely CSS-animated hover cards defining IDR's core model in an engaging way:
- **Academy**: Intensive training and practitioner bootcamps focusing on student and professional development.
- **Innovation & Incubation**: Developing proprietary risk models and forward-thinking AI governance strategies.
- **Advisory Services**: Expert guidance and hands-on NIST & ISO deployments including compliance auditing and strategic remediation.

### 4. Visual Lifecycle Pipeline
A custom chronological visual timeline seamlessly showcasing the core functional stages of IDR capabilities from training to deployment.

### 5. Community Partner Grid
Clean, dark-themed SVG badge integration for representing served sectors (GovTech, FinServ, Global Health, Infrastructure) ensuring trust and credibility.

### 6. Contact & Integration Hub
A native split-layout form for capturing user interest alongside physical location details, making it incredibly easy for users to get in touch.

### 7. 📱 Fully Responsive Modern Design
The entire experience is constructed utilizing modern, flexible design principles to ensure a pixel-perfect, highly readable layout regardless of what device is being used. Whether viewed on an ultra-wide desktop monitor, a laptop, a tablet, or a mobile smartphone, the layout recalculates structurally to preserve readability and aesthetic flow. 


## 🛠️ Tech Stack
This project was built adhering strictly to the requirement of using zero external UI frameworks (No Bootstrap/Tailwind).

**HTML5**: Semantic tagging (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) for structural integrity, precise SEO, and full accessibility compliance.

**CSS3**: Advanced Flexbox/Grid layouts, custom 3D keyframe animations, smooth scrolling mechanics, and a responsive color-variable system emphasizing high contrast (Orange/Black/White).

**JavaScript**: Lightweight, vanilla JS for essential DOM interactions such as the smooth mobile hamburger-menu switching.


## 📂 Project Structure

**`index.html`**: The core semantic landing page containing all structural layouts.

**`style.css`**: The central design system regulating layout, responsive grid scaling, typography, and premium 3D animations.

**`script.js`**: Native interactions for the mobile responsive navigation toggle.

**`assets/`**: Contains the custom-designed, scalable SVG brand logos, icons, and interface imagery.


## 🚀 Setup Guide
Simply double-click `index.html` to open and view it in any modern web browser—no servers, packages (`npm`), or build steps are required.
