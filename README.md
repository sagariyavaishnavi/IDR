# IDR | Institute of Digital Risk

The Institute of Digital Risk (IDR) bridges the gap between academic theory and real-world execution. IDR trains, equips, and deploys elite digital risk practitioners to secure the world's most regulated and high-consequence environments.

## Project Structure

This project uses a vanilla HTML/CSS architecture tailored for a high-contrast, modern interactive digital experience without reliance on external bloated frameworks. 

- `index.html`: The core landing page built on semantic HTML5 structure.
- `style.css`: The central CSS design system regulating layout, grid, colors, and premium css-animations.
- `script.js`: Basic DOM interactions (such as the mobile menu toggle).
- `assets/`: Contains core scalable SVGs and branding items utilized within the interface.

## Core Features

- **Pillars of Execution**: Outlines the Academy, Innovation & Incubation, and Advisory Services utilizing animated geometric hover states.
- **Cyber Network Visualizers**: Purely CSS animated geometry representations of practitioner and risk networks in real time space.
- **Custom Form Interactions**: Native high-contrast input collection for frictionless applicant and partner registration.
- **Accessible & Responsive Architecture**: Scales functionally from ultrawide monitors down to precise mobile grid structures. 

## Best Practices Maintained

- Use of proper `<section>`, `<nav>`, `<main>`, and `<footer>` semantics.
- High-contrast variable assignments prioritizing Accessibility.
- Implementation of purely Vector based (.svg) imagery to cut load-times completely.

## Color System

- **Primary Brand**: `#FF6B00` (Orange)
- **Primary Base**: `#0a0a0b` (Deep Base Black) -> Hero / Pillar Backgrounds
- **Primary Inverse**: `#FFFFFF` (White) -> About / Community Containers
